# Stadsfoto's badkamerstijl-stadslandingspagina's

Plaats hier per stad één hero-stadsfoto met exact deze naamgeving:

    public/badkamerstijl/steden/<slug>.avif

waarbij `<slug>` de `slug` is uit `src/data/cities.ts`.

Voorbeeld Amsterdam (slug `amsterdam`):

    public/badkamerstijl/steden/amsterdam.avif

Zodra het bestand hier staat laadt het automatisch als hero op de
bijbehorende stadslandingspagina. Er hoeft verder niets in de code te
veranderen. Aanbevolen formaat: liggend, circa 2200x1467px, .avif.
